### R3.1 EventStore append/load/subscribe

- `src/event-store.ts` 核心 API：
  - `nextVersion(streamKind, streamId)`：乐观并发版本号分配
  - `appendEvents(streamKind, streamId, expectedVersion, events)`：append 写入 + 版本递增
  - `loadStream(streamKind, streamId)`：重放 stream 全量事件
  - `subscribeStream(streamKind, streamId, onEvent)`：轮询订阅（10ms tick）
  - `OptimisticConcurrencyError`：版本冲突时抛出
- 配套测试 `src/event-store.test.ts`：append / load / subscribe / 并发冲突全覆盖

### R3.2 Outbox enqueue/claim/deliver + Worker 幂等

- `src/outbox.ts` API：
  - `enqueueOutbox(aggregateKind, aggregateId, eventType, payload)`：入队
  - `claimOutbox(workerId, limit)`：`SELECT ... FOR UPDATE SKIP LOCKED` 抢占
  - `completeOutbox(messageId)`：标记 delivered
  - `failOutbox(messageId, errorMessage)`：重试计数 + 退避
- `src/worker.ts`：`runWorkerOnce(db, handler, options)` 单轮拉取 → handler → 标记完成
- 幂等性由 `claimed_by` + 状态机保证（at-least-once，handler 必须自行幂等）
- 配套测试：`src/outbox.test.ts` + `src/worker.test.ts`，含 claim 互斥 / 失败重试 / 幂等

### R3.3 Projections

- `src/projections.ts` API：
  - `registerProjection(kind, handler)`：注册 reducer（事件 → 状态）
  - `applyProjection(kind, aggregateId, event)`：单事件应用到 projection_state
  - `rebuildProjection(kind, aggregateId)`：从 stream_events 0 号开始重放重建
  - 状态版本持久化：每次 apply / rebuild 写入 `projection_state.version`
- 配套测试 `src/projections.test.ts`：register / apply / rebuild + 状态版本单调递增

### R3.4 Snapshot + Crash recovery
