### 问题诊断

v5 load R8.x.2 subagent 的 commit (`196abebf`) 之后 LLM call 仍 timeout 10s。诊断分三层：

1. **baseUrl 错误**：`llm-provider.ts` 设 `baseUrl: "https://api.deepseek.com/v1"`，但 `openai-compatible.ts` 内部又会 append `/v1/chat/completions`。最终 URL `https://api.deepseek.com/v1/v1/chat/completions`（double /v1）→ DeepSeek 返回 404
2. **NO_PROXY 缺失**：v5 systemd process 走 `HTTPS_PROXY=127.0.0.1:7890`（mihomo proxy）出网。DeepSeek 经 mihomo 阻塞 → 10s timeout
3. **Secret push blocked**：用 systemctl + Environment= 在 service file 加 DEEPSEEK_API_KEY 时，commit 包含 secret literal → GitHub push-protection 拦截
