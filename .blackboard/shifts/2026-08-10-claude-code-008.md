### R4.0 Runtime Bridge

- 创建子包 `butler-v5/packages/runtime/`
  - `package.json`：`@butler/runtime` workspace 内部名
  - `tsconfig.json`：继承 `tsconfig.base.json`
- `src/bridge.ts`：EventBridge 消费 R3 persistence 公共 API（appendEvents / loadStream / subscribeStream / enqueueOutbox / runWorkerOnce），runtime 层不再直接 import `drizzle-orm` / `postgres-js`
- pglite 测试基线与 R3 一致（`makeTestDb` 复用 persistence 包导出）

### R4.1 AgentKernel

- `src/agent-kernel.ts`：状态机（idle → running → completed），强制状态转移单方向
- EventBridge 自动递增 streamVersion（消费 R3 `nextVersion` + `appendEvents`）
- 7 个状态转移测试覆盖：idle→running 允许 / idle→completed 拒绝 / running→completed 允许 / running→idle 拒绝 / 重入 running 拒绝 / 终态 completed 再触发拒绝 / 终态机断言

### R4.2 Decision Decoder

- `src/decision.ts`：`ModelDecision` ADT（`continue` / `toolCall` / `finish` / `reject`）
- 解码器解析 LLM 输出 → ADT + 校验，非法输入返回 `reject`
- 10 个 decoder 测试覆盖：合法 4 类 + 非法 6 类（缺字段 / 类型错 / 额外字段 / 空 toolName / finish 缺 reason / reject 缺 message）

### R4.3 Tool Runtime

- `src/tool-runtime.ts`：`runTool` 超时 + 取消 + 错误捕获
- 永不抛出契约：tool handler 抛错时返回 `Result.err` 而非冒泡
- 配套测试：超时取消 / handler 同步抛错 / handler 异步 reject / 正常返回 / capability 不匹配拒绝调用

### R4.4 Delegate Runtime

- `src/delegate-runtime.ts`：`delegate` 写 `ChildRunCreated` 事件 + outbox 消息
- capability 非空强制：空 capability 集合拒绝 dispatch（先校验后写事件）
- 配套测试：能力匹配 → 写事件 + enqueue outbox / 能力不匹配 → 拒绝且不写事件 / capability 为空 → 拒绝

### R4.5 Context Manager

- `src/context-manager.ts`：`estimateTokens` 基于字符数启发式
- `planCompression`：预算内不压缩、超预算触发压缩策略（保留最近 N 条消息 + 摘要较早消息）
- 配套测试：预算内原样返回 / 超出预算触发压缩 / 压缩后 token 数 < 预算 / 压缩不丢失最近系统消息
