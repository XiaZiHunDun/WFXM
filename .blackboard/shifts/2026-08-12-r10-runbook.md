## Phase 1: 1% traffic to v5 (15 min minimum)

**Owner actions:**
1. Change load balancer / gateway config: route 1% of incoming traffic to v5 endpoints
2. Wait 15 minutes
3. Capture metrics: v5 error rate, v5 p99 latency, v4 baseline error rate
4. Decision: proceed to 10% / hold / rollback

**Decision criteria:**
- Proceed: v5 error rate < v4 baseline + 1pp, p99 latency < v4 p99 + 50ms
- Hold: v5 error rate = v4 baseline ± 1pp, latency similar — investigate before proceeding
- Rollback: v5 error rate > v4 baseline + 1pp OR critical failures (5xx > 1% OR crash)

## Rollback drill (executed at least once during 24h)

**Trigger criteria:** any of:
- v5 error rate > 1% sustained 5+ minutes
- v5 p99 latency > 2x v4 p99 sustained 5+ minutes
- Critical path failure (auth / core API endpoints return 5xx)

**Rollback procedure:**
1. Change load balancer / gateway config: route 100% of traffic back to v4
2. Verify v4 is healthy (curl health endpoint, sample real traffic)
3. Pause v5 traffic (set v5 to 0%, leave v5 process running for diagnostics)
4. Capture rollback time: from trigger to v4=100%
5. File incident: `.blackboard/incidents/<ISO>-r10-rollback.md`

**Owner records:**
```
Rollback drill:
  trigger time: <ISO>
  trigger reason: <reason>
  rollback start: <ISO>
  rollback complete (v4=100%): <ISO>
  total rollback time: <seconds>
  v4 verified serving 100% after rollback: yes/no
  issues encountered: <description>
```

## 24h post-cutover monitoring

**Owner monitors continuously for 24h:**

- v5 p99 latency (target: < 500ms)
- v5 event-store lag (target: < 1000 events behind)
- v5 outbox processing rate (target: stable or growing)
- v5 CPU/memory utilization (target: < 80%)

## Success criteria (R10 closure)

R10 closes when:
- 4 phases complete (1% → 100%)
- All phase decisions = "proceed" (no rollback required for forward progress)
- ≥ 1 rollback drill executed within 24h, rollback time ≤ 60s
- 24h monitoring shows v5 error budget consumed < 50%
- No unresolved critical incidents

When all criteria met → commit data into shift card 015-preflight.md R10.3 section → AI runs R10.4 final closure.
