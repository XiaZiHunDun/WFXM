## 工作内容

会话本质是一次窄域 schema 修复。Claude Code 启动时打出三条警告：

- `hooks.PreToolUse.0.hooks: Expected array, but received undefined`
- `hooks.PostToolUse.0.hooks: Expected array, but received undefined`
- `hooks.Stop.0.hooks: Expected array, but received undefined`

根因：`.claude/settings.json` 把 `command` 直接放在 matcher entry 顶层，缺少 `matcher` 字段与 `hooks: [...]` 数组包裹层。Python 验证：

```python
for event in ("PreToolUse", "PostToolUse", "Stop"):
    for entry in cfg["hooks"][event]:
        # require "matcher" + "hooks": [{type:"command", command:str}]
```

修复后 `python3 -c 'json.load(open(...))' + 逐项 assert` 通过；下次启动 Claude Code 三条警告应消失。

### 关键判断

1. **matcher 选空字符串 `""`**：guard 脚本读 stdin JSON 内部自行判断 tool_name / file_path，不依赖 hook 层级过滤。
2. **保留原 command 不变**：用户原写是直白 python 调用，不涉及 env 提取或参数注入。
3. **未改动其他 settings key**，未触 user-level `~/.claude/settings.json` / `settings.local.json`，未触 `scripts/ai_guard/*.py`。
