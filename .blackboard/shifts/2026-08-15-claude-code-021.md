### R8.x.3 architecture

```
[wechat user] 
  ↓ iLink long-poll
[v4 wechat-gateway] (R8.2 forward_to_v5)
  ↓ POST /v1/wechat/inbound
[v5 routes.ts] → runButlerLoop(content, fromUserId, projectId)
  ↓
[wechat-inbound-butler.ts] AgentKernel flow:
  1. new AgentKernel({bridge, conversationId, projectId, actor})
  2. openTurn({userMessage: {role: "user", content}})
  3. loop (max 5 iter):
     a. build messages (system prompt + history + current user msg)
     b. provider.complete(messages, {tools: WEIBUTLER_LLM_TOOLS})
     c. decodeDecision(raw)
     d. switch _tag:
        - Respond → applyDecision (state=completed) → return reply
        - CallTool → runTool(tool, args) → continue loop with tool result
        - Finish → return fallback
        - AskApproval → return ask reply
  4. meta traces: {iterations, toolCalls, finalDecision, traces}
  ↓
[v4 iLink send]
  ↓
[wechat user] (real natural reply with tool-grounded context)
```
