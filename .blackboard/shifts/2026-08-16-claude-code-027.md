### 1. v4 systemd services — stopped + disabled

执行命令：

```bash
for svc in butler-gateway butler-runtime-lingwen butler-morning-brief \
           butler-push-drain butler-b9-weekly-gate butler-eval-sync \
           butler-ops-cadence-weekly butler-ops-cadence-quarterly; do
  systemctl --user stop "$svc.service"
  systemctl --user disable "$svc.service"
done
```

全部 8 个服务成功停用；其中 `butler-gateway.service` 同时清除了 `default.target.wants` 中的 symlink。

均清除了 `timers.target.wants` 中的 symlink。`butler-gateway.service` 无对应 timer（gateway 是长驻 service，非周期任务）。

### 3. v4 Python 进程清理
