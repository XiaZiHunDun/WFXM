### Spec deviations accepted

- **R7.3 deviation #1**: `pnpm-workspace.yaml` needs `- "cli"` entry
  - Spec 假设 cli/ 在 packages/* 或 apps/* 之内；实际 cli/ 在 `butler-v5/cli/`（与 packages/* 和 apps/* 平级），需要在 `pnpm-workspace.yaml` 显式追加 `- "cli"`
  - 影响：workspace 安装能正确识别 cli 包；不影响 pnpm install 正确性
- **R7.3 deviation #2**: `vitest.config.ts` needs `cli/**/*.test.ts` include glob
  - 同 fix 模式重复到 `tests/e2e/**/*.test.ts`（spec 未覆盖 e2e include）
  - 影响：vitest 能收集 cli + e2e 测试；不影响其它 include 路径
- **R7.3 deviation #3**: `cli/tsconfig.json` extends `../../tsconfig.base.json`（不是 `../` 也不是 `../../../`）
  - spec 文档给出 `../` 但 cli/ 实际仅 1 层深于 butler-v5/，需要 `../../tsconfig.base.json`
  - 影响：TypeScript 能正确继承 base；不影响 typecheck 正确性
- **R7.3 deviation #4**: Hono app has no `.listen()` — used `@hono/node-server`'s `serve({ fetch, port })` instead
  - spec 假设 Hono app.listen(port) 直接可用；实际但 Hono 默认导出为 `app.fetch` + `app.request`，需通过 `@hono/node-server` 适配 Node.js listen 接口
  - 影响：cli start 子命令能正确启动 HTTP server；不影响 Hono 路由定义
- **R7.4 deviation**: `vi.mock` of EventBridge in cli test
  - spec 未明确 cli test 是否需要 mock commander；实际 cli/index.ts 顶层 `new Command()` 立即执行 import 副作用，需 mock 隔离避免 vitest worker 不必要的 commander 实例化
  - 影响：cli test 隔离；不影响 cli 实际行为
