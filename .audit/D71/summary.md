- **T2: MCP HTTP/SSE SSRF + symlink path traversal** (SEC-001 + CQ-012 + CQ-011 + SEC-019)
  - Pre-D71 MCP transport only checked protocol (`http:` / `https:`); a typo'd operator config or hostile manifest could probe internal services. New isBlockedMcpHost() rejects RFC 1918, loopback, link-local, metadata ranges with explicit operator opt-out (`BUTLER_V5_MCP_ALLOW_PRIVATE_HOSTS=1`).
  - Pre-D71 isAllowedOutboundMediaPath only checked literal path; a symlink under `.butler-v5/` could redirect outside the root. New isAllowedOutboundMediaPathReal() uses realpathSync to resolve symlink chains before the allowlist check. Closes pre-scoped D70 #5.

- **T3: Telegram + Slack webhook user allowlist** (SEC-004 + SEC-005)
  - New BUTLER_V5_TELEGRAM_USER_ID_ALLOWLIST + BUTLER_V5_SLACK_USER_ID_ALLOWLIST env vars. Unset/empty preserves pre-D71 behavior (signed webhooks accepted from any user); set to harden against a leaked signing-secret scenario. SEC-003 (WS subscribe caller binding) deferred — per-caller identity requires bearer auth (D71+ scope expansion).
  - 2 sites closed.
- **T4: HTTP security headers + audit JSONL umask + owner-route 429 Chinese** (SEC-006 + SEC-007 + SO-005)

  - audit-log.ts sets umask 0o077 before mkdir so the JSONL lands 0o600 on multi-user hosts (was 0o644).
  - owner-routes.ts 429 → '请求过于频繁，请稍后再试' (was operator English "rate limit exceeded" left by D70 T4).
  - 3 sites closed.
- **T5: Spec/scenario cleanup** (SO-002 + SO-003 + SO-004)
